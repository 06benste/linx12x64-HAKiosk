Setting up Home Assistant

Find your Home Assistant URL

Open Home Assistant on a computer/phone and copy the address bar (just the part before any /lovelace/...), or check Settings → System → Network. It usually looks like http://homeassistant.local:8123 or http://192.168.x.x:8123.

Which dashboard should this tablet show?

Leave the Dashboard field blank to use whatever your default dashboard is. To show a specific one instead, open it on a computer/phone first and copy everything in the address bar after the port number — e.g. for a dashboard you created with URL path "kiosk" that's usually /kiosk; Home Assistant's auto-generated default dashboard is typically /lovelace/0.

Use a dedicated tablet account

Create a separate, non-admin user for this tablet: Settings → People → Add Person, and leave "Administrator" unchecked. If you fill in Username/Password above, that password is stored in plain text on the tablet — don't use your main admin account.

Or skip passwords: Trusted Networks

Leave Username/Password blank and add this to Home Assistant's configuration.yaml instead (replace the IP range and user ID with your own):

homeassistant:
  auth_providers:
    - type: trusted_networks
      trusted_networks:
        - 192.168.8.0/24
      trusted_users:
        192.168.8.0/24: KIOSK_USER_ID
      allow_bypass_login: true
    - type: homeassistant

Find the user ID under Settings → People → your tablet user, then restart Home Assistant.

Hiding the sidebar

Install the HACS "Kiosk Mode" module on the Home Assistant side and this tablet will hide the sidebar/header automatically — no need to add ?kiosk to the URL above, that's handled for you.

Setting up MQTT

Get a broker

In Home Assistant: Settings → Add-ons → Add-on Store, install "Mosquitto broker", start it. It runs on the same machine as Home Assistant, port 1883 by default.

Create a user for this tablet

Settings → People → Users → Add user (or the Mosquitto add-on's own config, depending on setup). Use that username/password here — don't reuse your HA admin login.

What this adds

Once enabled, this tablet appears as a device in HA with battery/power sensors, brightness/rotation controls, and (if the camera is set up) a live snapshot — all auto-discovered, no YAML needed.

Turning it off

Flip the switch above off and Save — the tablet stops publishing and its background service is disabled, without losing the saved credentials.
